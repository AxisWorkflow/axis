# Axis Help Index
> **Purpose:** Find where a topic is explained: each row names a topic, the words people use for it, and the sections of the User Manual, the Specification and the Introduction that cover it. `^help <topic>` searches this index. It explains Axis and is never authority over a Command, Practice or Rule.

Type `^help <topic>` in an Axis conversation and your Agent finds the matching rows for you, including close spellings and related words. To browse by hand, pick an area:

The User Manual explains how to use Axis. The Specification explains how it works, what it guarantees and where it stops. The Introduction is the short overview published with Axis on GitHub; it is not part of an installed project, so its links open the online page for the document version. They need internet access; local Manual and Specification links remain available offline.

The Topic Index tables at the end of those three documents are generated from this file. To add or move a topic, edit its row here.
