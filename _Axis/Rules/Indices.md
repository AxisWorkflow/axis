# Indices
> **Purpose:** Which record families carry an index file and which are their own directory listing.


- Logs, Notes, Ideas, Follow-Ups, Reminders, CX Reports, Audit Reports, Status Reports, and Markers (`Agents/`) have no index file (directory IS the index).
- Tasks are indexed & summarized in `TASKS.md` (more than just a dir listing).
- Snapshots are indexed & summarized in `SNAPSHOTS.md` (more than just a dir listing).
- Include a link to "Details..." when an index entry has a supporting detail file.
