# References and Links
> **Purpose:** How an Axis Reference resolves, and the external links to hand User.


- Square braces followed by parentheses are file links - for example: `[...](...)`.
- Example: [Practices > Agents] refers to the file `_Axis/Practices/Agents.md`.
- Every reference resolves via the table in [Practices > References] - no heuristic resolution.
- [Practices > X] resolves to the single-token file `_Axis/Practices/{X}.md`; a deeper form ([Practices > X > Y]) names a heading inside that file.
- A reference to "... in Settings" refers to a Setting in `_Axis/SETTINGS.md`.
- References to Axis, the Workflow, and the Axis Workflow are all synonymous.
- When subject is missing in prose, assume that it refers to "you", the Agent.
