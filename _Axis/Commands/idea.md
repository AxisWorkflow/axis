# ^idea
> **Purpose:** Save an Idea into `_Axis/Ideas/` for future exploration.

1. The `^idea` command must be followed by whitespace and additional text - the full detail of the Idea. If the text is missing: ask User for it (i.e., ask User to describe the idea), then continue.

2. Read [Practices > Ideas] for the record format.

3. Draft the Subject for Line 1 (≤ 80 chars) using your judgment, and select a status and priority for the Idea.

4. Save the Idea as `_Axis/Ideas/{yyyy.mm.dd.hh.mm.ss.xxxZ}.md`. STOP.
