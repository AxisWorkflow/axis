# ^profile
> **Purpose:** Select a Profile, change Settings, and draft a Mindset.

1. Review the available Profiles in `_Axis/Resources/Template-Profiles.md` and ask User to select one. If User declines: STOP.

2. Look up the Setting values for the selected Profile in [Template-Profiles] (the `## {Profile} Profile` section, `#### Settings` subsection) and save each value into the corresponding Setting in `_Axis/SETTINGS.md`.

3. Follow `_Axis/Resources/Draft-Mindset.md` to regenerate the Mindset.

4. Log one Event: `Profile selected: {ProfileName}`. STOP.
