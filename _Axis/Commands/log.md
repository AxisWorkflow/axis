# ^log
> **Purpose:** Manually Log an entry into `_Axis/Logs/`.

1. The `^log` command must be followed by whitespace and additional text - the full detail of what should be logged. If the text is missing: ask User for it (i.e., ask User to describe the issue to log), then continue.

2. Draft a Subject line for the entry (every Log needs one on Line 1), using your judgment.

3. Log the item per [Practices > Logs] (Line 1=Subject, Line 2=blank, Line 3=`by:` author, Lines 4+ = body). STOP.
