# ^memo
> **Purpose:** Write or update a Memo for User in `_Memos/`.

1. Main Agent only. An External Agent proposes the content to Main through a Message under [Practices > Messages] and STOPs.

2. Load [Practices > Memos]. The text after `^memo` names the subject or what to cover; with no text, cover the current discussion.

3. Record any decision, task or open ask in its canonical record first. If a live memo from today covers the same subject, update it and add an Updates line; otherwise write a new one under [Practices > Memos].

4. Log one Event naming the memo, then reply with a few lines of outcome and a link to the memo. STOP.
