# ^ideas
> **Purpose:** Review Ideas - update status and priority, archive, and surface top priorities.

1. Read [Practices > Ideas] for format and review guidance.

2. Compile a live index of `_Axis/Ideas/` (scan filenames, Line-1 subjects, and fields). If there are no Ideas: tell User and STOP.

3. Review each Idea in the context of recent project developments:
	- a. Update `status:` and `priority:` as warranted.
	- b. Set `reviewed:` to a current UTC timestamp for any Idea reviewed at more than a superficial level.
	- c. Suggest archiving Ideas that are obsolete or absorbed into the Plan or Tasks; use `^archive` for the confirmed move.

4. To the extent consistent with your Settings and Mindset, add new Ideas uncovered by the review.

5. Summarize the top priorities back to User.

6. Log one Event for the review. STOP.
