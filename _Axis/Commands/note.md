# ^note
> **Purpose:** Manually save a Note into `_Axis/Notes/`.

1. The `^note` command must be followed by whitespace and additional text - the full detail of the Note. If the text is missing: ask User for it (i.e., ask User to describe the detail for the Note), then continue.

2. Draft a Subject line for the Note (Line 1, ≤ 80 chars; Line 2 blank; Lines 3+ body) per the Index-Detail Pattern.

3. Save the Note as `_Axis/Notes/{yyyy.mm.dd.hh.mm.ss.xxxZ}.md`.

4. Consider the new Note in the context of the project (see [Practices > Notes]): if it implies something important, surface that with User and suggest how to incorporate it.

5. If the active count now exceeds [Settings > Max Notes], follow [Practices > Archiving > Automatic Note Overflow]. If any Note moves, tell User and Log one Event listing the paths and verification result. STOP.
