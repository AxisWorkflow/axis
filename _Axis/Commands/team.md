# ^team
> **Purpose:** Create and control an Axis Team of Agents.

1. Verify your own lease and apply the Command role gate. Support create/status/pause/resume/stop. Load [Practices > Coordination] and [Practices > Messages]. Status is read-only. Main alone creates a charter or accepts controls. Preview objective, separate leader/membership, authority, scopes, validator, finite limits and stop conditions; resolve missing User authority before admission. Create immutable records and rebuild views using the helper or equivalent manual procedure. Dispatch only within the approved charter and valid lease. A stop reports confirmed and unconfirmed workers, never claims instant interruption.

2. Report only useful state, outcomes and blockers. Log any state change under [Practices > Logs]; read-only inspection writes nothing. STOP.
