# ^team
> **Purpose:** Create and control an Axis Team of Agents.

1. Verify your lease and apply the Command role gate. Support create/status/pause/resume/stop and read-only plan preview. Load [Practices > Teams] for create or a method change; load [Practices > Coordination] and [Practices > Messages] for lifecycle actions. Main alone admits charters or accepts controls. Existing authority carries through ordinary corrections and finalization.
2. For preview, use `_Axis/Resources/team-plan.py {plan.json}` or the equivalent manual checks in [Practices > Teams]. Present a suitable method, separate leader/members, participation, actual budget, deliverables and acceptance. Preview never grants authority or proves capacity. Ask only for unresolved consequential choices or genuinely missing authorization.
3. Create immutable records and rebuild views through the helper or equivalent manual procedure. Embed an optional checked `collaboration_plan`; retain prose-only plans as manual/unclassified. Dispatch only under the current grant, verified capacity and lease. Direct peer communication and owned workspaces follow the charter; Main need not relay routine exchanges.
4. Report useful outcomes, actual Main obligations and limitations. At a real budget boundary preserve work, pause affected execution and ask for an extension; counts and phase targets are not independent budgets. A stop reports confirmed and unconfirmed workers, never instant interruption. Log state changes; read-only inspection writes nothing. STOP.
