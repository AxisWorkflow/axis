# ^onboard
> **Purpose:** Guide a new User through a five-minute tour - one Note, one Idea, one Status Report.

1. Offer the tour in two lines: you will capture one Note, one Idea, and generate the project's first Status Report - about five minutes, and everything lands in the project for keeps. If User declines: STOP.

2. Note. Explain in one line: a Note is a short-term fact the project should remember between sessions. Ask User for one real fact worth keeping (a deadline, a preference, a constraint). Save it per [Practices > Notes], and tell User where it landed (`_Axis/Notes/`).

3. Idea. Explain in one line: an Idea is a speculative thought to revisit as the project evolves. Ask User for one. Save it per [Practices > Ideas], and mention that `^ideas` reviews them later.

4. Status. Run the `^status` command to generate the project's first Status Report, and present the link.

5. Close with a 3-line hint card:
	- Type `^help` to list all commands (and `^dashboard` for the live overview).
	- Drop files anywhere in the project folder - Agents read and organize them into Subfolders; Wiki sources go to `Wiki/Inbox/`; keep untouchable originals outside the project.
	- Ask for a Plan (`^plan`) or the Wiki (`^wiki`) whenever you are ready.

6. Log one Event for the tour. STOP.
